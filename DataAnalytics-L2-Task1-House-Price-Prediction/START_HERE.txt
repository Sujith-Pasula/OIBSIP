HOUSE PRICE PREDICTION — START HERE

1. Extract the ZIP and open the folder in VS Code.
2. Open Terminal > New Terminal (PowerShell).
3. Run:
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   python src\house_price_prediction.py

The script downloads the dataset and creates charts, metrics, predictions, coefficients, and a report in outputs/.

If activation is blocked:
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\.venv\Scripts\Activate.ps1

Use metrics generated by your run in the README/demo.

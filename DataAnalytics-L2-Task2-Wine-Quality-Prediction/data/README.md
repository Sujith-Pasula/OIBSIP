# Dataset source
The script downloads the UCI Machine Learning Repository Wine Quality red-wine data:
https://archive.ics.uci.edu/ml/machine-learning-databases/wine-quality/winequality-red.csv

The CSV is semicolon-delimited. It contains physicochemical measurements and the original integer quality score. The project preserves the original multiclass quality labels so that class-level performance can be inspected. Internet is needed for the initial download; once downloaded, the script reads the local copy.

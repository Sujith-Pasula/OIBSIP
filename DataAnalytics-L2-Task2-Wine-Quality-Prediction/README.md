# Wine Quality Prediction
**Oasis Infobyte — Data Analytics Internship | Level 2, Task 2**

This project predicts wine quality scores from physicochemical measurements. It performs EDA, checks class distribution and imbalance, uses a stratified train/test split, compares Random Forest, SGD Classifier, and SVC, and saves classification metrics, confusion matrices, and feature importance.

## Dataset
The script downloads the UCI Wine Quality red-wine dataset on first run. It contains physicochemical features and a sensory quality score. The data uses a semicolon (`;`) delimiter. The target is the original integer `quality` score; no artificial labels are created.

Dataset source: UCI Machine Learning Repository, Wine Quality dataset. See `data/README.md`.

## Methodology
1. Inspect shape, data types, missing values, duplicates, and summary statistics.
2. Plot the distribution of quality scores and numeric correlations.
3. Use an 80/20 stratified split to preserve the class proportions.
4. Standardize features for SGD and SVC; train Random Forest as a tree-based baseline.
5. Compare accuracy, macro-F1, weighted-F1, and classification reports.
6. Inspect confusion matrices and Random Forest feature importance.

## Important interpretation notes
- Wine quality labels are imbalanced: some quality scores occur much more often than others. Accuracy alone can hide poor performance on minority classes, so compare macro-F1 and class-level precision/recall too.
- The dataset is red wine from a particular data collection; it is not a universal model of all wines.
- These are educational results, not a commercial wine certification system.
- Use the actual metrics generated by your own run. Do not copy invented metrics into your README or demo.
